# DEALIVO V1

Prototype mobile-first de l’application **DEALIVO** : promotions, coupons, cashback simulé, prix net, score produit, liste de courses et scan code-barres via Open Food Facts.

Les offres commerciales sont fictives dans cette V1. Les données non disponibles ne sont jamais présentées comme réelles.

## Déploiement Netlify

Publier le contenu de ce dossier comme site statique. Le fichier `netlify.toml` définit la racine de publication.
