# DEALIVO V1

Prototype mobile-first de l’application **DEALIVO** : promotions, coupons et recherche de bons plans.

La V1 contient désormais un premier jeu d'offres commerciales recensées comme actives au 21 octobre 2026. Les offres sont accompagnées de leur source, date de validité et conditions principales. Une offre « vérifiée par source » n'est pas présentée comme un test de panier : les conditions du marchand restent prioritaires.

## Déploiement Netlify

Publier le contenu de ce dossier comme site statique. Le fichier `netlify.toml` définit la racine de publication.

## Fiabilité des offres

Les promotions et codes doivent être ré-audités régulièrement. DEALIVO ne doit jamais inventer un prix, un code ou une remise. Les offres expirées doivent être retirées ou marquées comme expirées.
